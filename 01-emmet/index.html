01-EMMET

Plugin for faster HTML and CSS coding.

01-Child: >
Creates child elements (nesting).

Example:

ul>li>a🔀

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: +
Creates sibling elements.

Example:

section+header+nav↔️

Result:

<section></section> <header></header> <nav></nav>

03-Multiplication: *
Creates multiple elements.

Example:

li*3🔁

Result:

<li></li> <li></li> <li></li>

04-class: .
Creates elements with a specific class.

Example:

menu.mainmenu↔️

.container↔️

Result:

<menu class="mainmenu"></menu> <div class="container"></div>

05-classes: ...
creates multiple class attributes.

Example:

menu.mainmenu.uppercase.blue↔️

Result:

<menu class="mainmenu uppercase blue"></menu>

06-id: #
Creates elements with a specific ID.

Example:

nav#menu

Result:

<nav id="menu"></nav>

07-text: {}
inserts text content into an element.

Example:

div{lorem ipsum dolor}
a{Click here}

Result:

<div>lorem ipsum dolor</div> <a href="">Click here</a>

08-Custom attributes: []
creates custom attributes

Example:

a[href="https://www.google.com"]

Result:

<a href="https://www.google.com"></a>

09-Item Numbering: $
adds sequential numbers to elements

Example:

ul>li.num$*3
section>article.sec$$$*3

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul> <section> <article class="sec001"></article> <article class="sec002"></article> <article class="sec003"></article> </section>

10-Reverse Numbering: @-
adds reverse sequential numbers to elements

Example:

ul>li.num$@-*3

Result:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Numbering: @n
defines a base number for sequential numbering

Example:

ul>li.num$@n3*4

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb up: ^
moves up one level in the hierarchy

Example:

section>article>div^p↔️

Result:

<section> <article> <div></div> <p></p> </article> </section>

13-Grouping: ( )
Groups elements together.

Example:

(header>nav)(section>article)

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-lorem: lorem
Generates placeholder text.

Example:

lorem5

Result:

Lorem ipsum dolor sit amet.

15-HTML Documents: html:
Generates a basic HTML document structure.

Example:

html:xs html:xt html:5 html:4t html:4s

Result:

<!DOCTYPE html> <html lang="en"> <head> <title>Document</title> </head> <body> </body> </html>

16-Meta tags: meta:
Generates meta tags.

Example:

meta[name=viewport][content= "width=device-width, initial-scale=1.0"]

Result:

<meta name="viewport" content= "width=device-width, initial-scale=1.0">
